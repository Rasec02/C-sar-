Proyecto web estático para "Barbería Navaja", bajo el concepto "Estilo clásico, servicio moderno", desarrollado como práctica integradora de Programación Web. Consta de cinco vistas HTML enlazadas Inicio, Sobre nosotros, Servicios, Contacto e Iniciar sesión que comparten header, nav, footer y un único archivo CSS externo en la carpeta css/. Se aplicó estructura semántica completa (header, nav, main, section, article, aside, footer), metaetiquetas SEO en cada página, diseño responsivo mobile-first y soporte para tema claro/oscuro con prefers-color-scheme. La vista Inicio incluye un hero con animación de entrada; Sobre nosotros usa CSS Grid en dos columnas con imagen y lista; Servicios presenta tarjetas con Flexbox, transición hover y tabla de precios; Contacto tiene un formulario con cinco campos validados y etiquetas vinculadas; y Login incluye usuario, contraseña, checkbox y enlaces auxiliares.
